# Ohio Golf Club design research

Style guide research for ohiogolfclubindoor.com, taken from the rendered public site.

- `style-guide.html`: the visual style guide (the Vercel preview opens it at `/`)
- `audit.md`: component and pattern inventory, inconsistencies, open questions
- `HANDOFF.md`: scope, what's verified, and the prompt for the next session
- `tokens/tokens.json`: observed tokens in W3C design tokens format; `tokens/report.json` has every value with counts
- `raw/`, `screenshots/`: capture data

To re-run: `npm install`, then `npm run capture`, `npm run tokens`, `npm run guide`.
